### Repository facts checked by hand

- The cached `k` is taken after `apply_rope` (line 439) and before
  `repeat_interleave` (461), so the cache holds H<sub>kv</sub> rotated heads.
- `native_gqa_matches_repeat_interleave` uses `n_kv_head=1`; with one
  key/value head the grouping order cannot matter, so the test would not catch
  a tiled native path. Stated in the chapter.
- No `docs/RESULTS.md` section varies `n_kv_head` at the pin (grep for "kv",
  "GQA", "n_kv_head").
