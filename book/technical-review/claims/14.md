### Repository facts checked by hand

- `_grow` computes angles in fp32 (`t` and `inv_freq` fp32) before casting
  the tables to `dtype`.
- `_route_grouped` stacks expert weights in bf16 (716) and casts the inputs to
  bf16 (743), so on the released configuration the experts run in bf16 even
  when the model is fp32; the measurement's `sparse` run sets
  `layer.mlp.impl = "sparse"` at runtime to compare.
- A scratch probe (not in the book) confirmed that two runs at offset 0 give
  bit-identical logits on both paths, so the drift is from the offset.
