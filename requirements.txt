# AnuLM's model, training, sampling, serving and every evaluation need
# exactly one third-party package: torch. safetensors is needed only to read
# or write an exported checkpoint folder, pyarrow only to read Hugging Face
# parquet shards; both are listed below and neither is imported by the
# training path. docs/DEVELOPING.md "Setup" says which script needs what.
#
# CPU-only (what sections 1-5 of docs/RESULTS.md ran on):
#   pip install --index-url https://download.pytorch.org/whl/cpu torch
# CUDA: follow https://pytorch.org/get-started/locally/ for your driver.
#   Every 350M-class run used an NVIDIA card (RTX 5050, then RTX 5070 Ti,
#   torch 2.11.0+cu128 on Python 3.14.7, Windows).
#
# >=2.1 is the floor for torch.nn.functional.scaled_dot_product_attention
# accepting a `scale=` argument, which both attention implementations rely on.
# `--moe-impl grouped` additionally needs torch.nn.functional.grouped_mm
# (present in 2.11).
torch>=2.1

# Reading and writing the exported (Hugging Face) checkpoint folders:
# export_hf.py, and load_checkpoint() when given a folder instead of a .pt.
safetensors>=0.4

# Optional: only the converters that read Hugging Face parquet shards need it
# (convert_parquet.py, convert_translate.py, and eval_code.py for the MBPP
# test file). The fetchers, the tokenizer, training and the web UI do not.
pyarrow>=15

# Optional: only app.py (the Gradio demo, demo_colab.ipynb, a Hugging Face
# Space) needs these. space/requirements.txt pins gradio>=6, which is what the
# Space front matter declares; locally anything from 5 on works.
# gradio>=5
# huggingface_hub>=0.30

# Optional: the speech work (voice.py, audio_codec.py, speech_*.py,
# eval_speech.py, app_voice.py). None of it is imported by the text training,
# sampling or serving paths.
#
# The cascade demo -- Whisper hears, Piper speaks:
# faster-whisper>=1.2
# piper-tts>=1.8
# sounddevice>=0.4          # only for voice.py --mic / --play
#
# The end-to-end path -- speech as tokens in the model's own vocabulary:
# snac>=1.2                 # the neural audio codec, pure torch
#
# Vision (vision_encoder.py). Install these with --no-deps and a pinned
# torchvision, or pip resolves a NEWER torch and replaces the +cu128 build:
#   pip install --no-deps torchvision==0.26.0 timm pillow
# torchvision 0.26 is the build that pairs with torch 2.11; it lands as
# +cpu, which is fine because only timm's pure-torch ViT is used and it runs
# on whatever device it is moved to.
# torchvision==0.26.0
# timm>=1.0
# pillow>=10
#
# Deliberately absent: transformers. Mimi and the transformers Whisper would
# both be reasonable choices, but on the training box Smart App Control blocks
# scipy's unsigned _rigid_transform_cy.pyd and transformers imports scipy
# through its object-detection loss, so every model class there fails. snac,
# faster-whisper and piper-tts are pure torch or self-contained and survive.
#
# Two Windows traps, both handled in code but worth knowing:
#   * ctranslate2 wants cublas64_12.dll, which the cu128 torch wheel ships in
#     torch/lib without exporting it -- audio_codec.ensure_cuda_dlls() adds it.
#   * `pip install torchvision` (or open_clip_torch) resolves a NEWER torch and
#     will replace a pinned +cu128 build. Always --dry-run first.
